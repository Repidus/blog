- '김영한의 실전 자바 - 기본편' 53강 'static 변수1'부터 60강 '정리'까지 수강하고, 퀴즈를 풀어 섹션 8 '자바 메모리 구조와 static'을 한 번에 마쳤다.
  - static 변수의 개념은 특별히 새롭지 않다. C/C++과 파이썬을 공부할 때 이미 배운 개념이다.
  - "static 변수는 프로그램이 시작할 때 메모리 공간에 생성된다"
    - 정적이라는 이름과 같이 프로그램 실행 내내 메모리 공간에 남아서 움직이지 않는다.
  - 변수의 종류에 따라 생성되는 메모리 영역이 다르다.
    - 지역 변수: 스택 영역
    - 멤버 변수: 힙 영역
    - static 변수: 메서드 영역
  - static 메서드는 인스턴스 대신 클래스에 종속된 메서드로, 불필요한 인스턴스 생성 없이 바로 메서드를 사용할 수 있다.
    - `println` 호출과 비슷해 보이는데.
  - static 메서드는 자기 클래스의 static 변수/메서드만 접근이 가능하지만, 인스턴스 메서드는 자기 클래스의 static 메서드와 인스턴스 메서드, static 변수와 인스턴스 멤버 변수에 모두 자유롭게 접근이 가능하다.
    - 생각해 보면 금방 알 수 있는 부분이다.
    - static 메서드가 인스턴스 메서드에 접근하는 경우는, 매개변수로 넘겨받은 객체의 인스턴스 메서드를 호출하는 경우뿐이다.
    - 유틸리티성 메서드 묶음을 갖는 클래스에서 자주 쓰인다.
      - 수학 처리 등
    - `import`문을 사용해 static 메서드 호출에서 패키지명, 클래스명을 생략할 수 있다.
    - `main` 메서드도 static 메서드이기 때문에 `main()`에서 호출하려는 같은 클래스의 메서드에는 static 키워드가 필요하다.
  - 생성자를 `private`으로 두면 유틸 클래스의 객체 생성을 막을 수 있다.
