## 2025년 11월 11일 화요일

- 어떤 프로젝트를 하든 개발일지를 쓰려면 블로그가 필요할 것 같다.
- 블로그를 만들 때 사용하려고 늘 생각했던 Django를 통해 개발해 보자.
- 사둔 책 \<Do it! 점프 투 장고>(박응용 저)가 있어 이를 활용하기로.
- 가상 환경을 하나 만들었는데, activate 관련 실행 파일이 3개나 있어(activate.bat, Activate.ps1, activate) Gemini에게 물었다. (출처 확인함)
  - TIL: 파이썬 모듈 venv는 모듈의 사용자가 어떤 콘솔 환경에서 개발하든 독립성을 보장하기 위해 3가지 경우 모두 사용할 수 있는 스크립트 파일을 만들어 두었다고 함
    - 파이썬 개발 환경을 설치할 때 윈도우를 선택했으므로 설치된 파이썬은 해당 컴퓨터 OS가 윈도우임을 알지만, venv 사용자는 윈도우 시스템을 여러 콘솔 환경에서 제어할 수 있기 때문
  - activate 관련 스크립트는 여러 개인데 deactivate는 deactivate.bat 하나밖에 없어 Gemini에게 물었더니, PowerShell이나 Git Bash는 activate 동작 안에 deactivate를 내장하고 가상 환경 종료 시에 activate 동작을 마치면서 함께 수행하는 방식으로, 따로 스크립트를 필요로 하지 않는다고 함. (출처 확인함)
    - Deactivate하지 않고 shell을 종료해 버렸을 때는 어떤지 Gemini에게 물었는데, shell 종료와 함께 가상 환경도 함께 종료되므로 걱정할 필요가 없으며, deactivate는 가상 환경을 종료하고도 shell을 유지하고 싶을 때 사용하는 명령어로 이해하면 된다고 함. (출처 확인함)
- Django 프로젝트를 생성하는 start-project 명령에서 오류가 발생해 Gemini에게 물었는데, 장고가 요구하는 파이썬 모듈이 현재 버전(3.12)에서는 기본 내장 모듈에서 빠진 탓. (출처 확인함)
  - 따로 분리된 모듈을 설치하는 것으로 간단히 해결할 수 있고, Gemini도 이를 추천했으나 2021년에 출판된 책에 따라 장고 버전을 낮추어 설치한 데 문제가 있다고 보고, 파이썬과 버전을 맞춰야겠다고 판단함.
  - 책의 버전에 맞게 파이썬을 다운그레이드할 수도 있고, 장고를 최신 LTS 버전으로 업그레이드할 수도 있다. 다만 책에서 파이썬 버전을 명시하지 않은 점이 마음에 걸려 앞으로의 진행 상황에서도 설명이 부족할 수 있겠다고 판단해, 장고를 업그레이드하기로 함.
    - 이후 과정에서 생길 수 있는 책과 프로젝트의 간극은 Gemini를 적극적으로 활용해 최신 버전에 맞게 실습하기로 함. 걱정이 없지는 않지만, 장고가 지금도 널리 쓰이는 프레임워크이고 AI 챗봇의 성능에 낙관하며 일단 지켜보기로.

## 2025년 11월 12일 수요일

- 여러 shell이 모두 Windows 위에서 구동될 텐데 왜 굳이 UNIX-like 등의 다른 명령을 사용하는 shell을 써야 하는지 의문이 들어 Gemini에게 물어봄 (출처 확인함)
  - TIL: 콘솔 환경, 즉 shell은 윈도우 시스템 위에서라도 명령 프롬프트(Windows Command Prompt), PowerShell, Git Bash 등의 대표적 3가지를 비롯한 다양한 선택지가 있다. 이는 모두 윈도우 시스템을 상정하고 동작하나, 특유의 명령어 체계(특히 Git Bash의 UNIX-like 스크립트)를 활용할 수 있는 것은 각 shell이 운영체제에 맞는 명령을 emulate하기 때문이라고. (Gemini에게 묻고 출처 확인함)
    - 장점으로는 유닉스 기반 스크립트를 수정 없이 재사용할 수 있다는 점 등이 있다.
